# HTML Rendererの検査

`just html-ci`は型・CSS正本・実WASMとの結合を検査します。
WASMは先に`just wasm-build`で用意し、HTMLの検査中にはRustを起動しません。

`tests/unit/`はコード本文・Unicode・軟改行・公開IDと目次・私的メタデータの非漏洩・frontmatter・診断表示・配送済みメディア・HTML固有のSVG表示制約を焦点ごとに守ります。
実WASMと実ファイル、ローカルHTTPを使い、モックは用いません。

構文拒否、正規化、SVG安全性と内部ID隔離はCoreの検査が所有するため移していません。
CLIの引数と配信サイトの検査も、このパッケージへ持ち込みません。

旧Rendererが消費側に残る移行期間は、その実装の検査も消費側に残ります。
切り替え完了後に旧実装と一緒に撤去します。
見た目と操作の比較は移設時の実画面で行います。

# 資産の取り扱い

## 新規コード

Yomiloで新規作成するソースコードのライセンスは **MIT** とする。
`LICENSE` を正本とする。

## 既存 `own/web` から集めた資料

CSS・操作スクリプト・アイコンは一度`packages/yomilo-html/`へ移設したが、本文のHTMLとフックだけを返す形へ絞る際に利用側へ移し、Yomiloの製品からは外した。
比較用に置いていた移設前のスナップショットも削除し、Yomiloには残していない。

### フォント本体

Yomiloのパッケージはフォント本体を同梱しない。
最小テーマは環境の書体を使い、MoralerspaceやSoraなど第三者フォントの原本とOFLは、それを使うテーマを持つ利用側が管理する。

## PoC

`experiments/phase0-rust/` は既存の検証コードのコピー。
製品実装と区別し、検証結果は `experiments/phase0-rust/README.md` を参照する。
PoC内の例は環境依存のパスを含む可能性がある。

# ADR 0001: Yomiloの基本方針

- 状態：承認済み方針・実装済み
- 日付：2026-10-12

## 決定

1. プロダクト名を **Yomilo** とする。実装はRustを第一候補とし、TypeScriptのブラウザ操作・統合層を許す。
2. Coreは厳格Markdownの**構造化と共通文書モデル**までを担当する。描画準備・Renderer・Adapterは論理的に分離する。
3. 初期は生成側で構造化・描画準備を行い、表示環境が描画を行う。静的Web/CLIでは生成側でHTML描画まで完了してよい。
4. 初期には端末内の構造化・描画準備やネイティブFFIを作らない。実需が生じたら再検討する。
5. 新規コードはMITとする。第三者フォントなど別ライセンスの資産は分離する。

## 根拠

`experiments/phase0-rust/` のPoCでRust Markdown解析・WASM・Astro最小連携・コード構文スコープ・簡易ディレクティブ処理を確認した。正式な描画互換性・配布は未検証。

## 未決定

実装ライブラリの最終選定、ディレクティブの完全な文法、配布方法、公開済み記事のバージョン固定の詳細。版を持つ文書モデルと**必要時の静的スナップショットによる凍結**を基本案とし、古い実行エンジンを無期限に保持する義務を前提にしない。最終的な移行・修正方針は別ADRで確定する。
